# 店员操作手册

> 日常经营在手机上完成:手机浏览器打开后台地址(或点主屏幕「商城后台」图标),用店铺账号登录。
> 也可以从小程序「我的 → 商家管理」进入。登录一次可保持 30 天。

## 一、来新订单了(最重要!)

来单时企业微信群会弹「🔔 新订单待发货」消息;后台顶部铃铛也会显示待处理数量。

1. 打开后台 → **订单管理** → 「待接单」标签
2. 点订单上的 **「接单」** → 顾客那边会显示「备餐中」,开始做货
3. 做好打包后点 **「发货」** → 填快递公司和单号 → 确认
4. 顾客收货后自己点确认;超时未点的订单保持「已发货」即可

> 着急发货可以点「直接发货」跳过接单一步。

## 二、菜品售罄/补货

- **售罄**:商品管理页,把该商品右侧的**绿色开关**拨灰 → 顾客立刻看不到它
- **恢复**:再拨回绿色
- **改库存**:点商品的库存数字 → 弹窗里 ±1/±10 或直接输入 → 保存
  - 带「规格」标记的商品要进「编辑」里改各规格的库存
- **库存标红** = 只剩 5 件以内,尽快补货(进后台时也会弹提醒)

## 三、每日开档/收档

商品管理页右上:
- **一键开档** = 全部上架(可先选分类,只操作该分类)
- **一键收档** = 全部下架

## 四、顾客要退款

**顾客自己能退的**:付了款但我们还没接单的订单,顾客可在小程序里自己点「申请退款」。

**需要我们操作的**(已接单/已发货后顾客电话协商,或顾客自己申请了退款):
1. 订单管理找到该订单 → 点红色 **「退款」**(顾客已申请的单在「退款」标签页,按钮叫「发起退款」)
2. 第一步弹窗:核对订单号、金额、顾客电话,可以填退款原因 → 「下一步」
3. 第二步红色弹窗:**手动输入退款金额**(必须和订单实付一模一样,比如 38.00)→「确认退款」
4. 钱会自动原路退回顾客微信,**不用再去商户平台操作**。几秒后订单变成「已退款」,企微群会收到「退款已到账」

> 输错金额按钮是灰的点不了,这是故意的,防手滑。
> 如果显示「微信处理中」超过 10 分钟,或企微群收到「退款异常」,联系开发或到商户平台看退款记录;确认微信那边已经退成功但后台没变,再点「手动标记完成」。

## 五、换首页轮播图

**轮播管理** → 新增 Banner → 上传图片(建议横图 690×280)→ 可选择点击跳转到某个商品 → 保存。
不想展示了就点「下架」,图留着下次还能用。

## 六、上新菜品

**商品管理** → 新增商品 → 填分类、名称、价格、库存 → 上传封面图和详情图(手机直接拍照就行,系统会自动压缩)→ 如有辣度/克重等多规格,在「商品规格」里加维度和价格 → 保存。

## 七、遇到问题

- **后台打不开**:确认手机和服务器网络正常;联系管理员
- **忘记有没有发货**:订单点「详情」能看到完整进度和物流单号
- **误下架了商品**:开关拨回来就行,数据不会丢
- **数据看着不对**:先下拉刷新;仍异常联系管理员,不要自己多次重复操作
