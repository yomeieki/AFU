# 分类页渠道标识 设计

日期：2026-09-17　作者：Claude（00 规划前置设计）　状态：待店主审阅

## 0. 一句话

同城分类页的门店头第一行右端加一枚「同城配送 ▾」标识，点它切换渠道；邮寄分类页放在搜索框那一行右端。顺带把主页上那枚被微信胶囊压住的同名标识挪开。

## 1. 已拍板的决策

| # | 决策 | 结论 |
|---|---|---|
| N1 | 位置 | 与店名同一行的**右端**（店主 2026-09-17 定）。**不放右上角**——微信胶囊钉死在那儿，页面盖不过它 |
| N2 | 邮寄侧 | 没有门店头，放搜索框那一行右端，保持一致的位置感 |
| N3 | 交互 | 点它弹出切换层（同城配送 / 全国邮寄，当前项打勾），选中即切渠道并重载本页 |
| N4 | 底部标签栏 | **不动**（店主 2026-09-17 决定：封面不进底部、主页保留）。本批与导航结构无关 |
| N5 | 主页那枚旧标识 | 主页用自绘导航栏，`.navbar-channel` 定位 `right: 24rpx`，实际会落在微信胶囊底下。本批顺手挪到胶囊左侧 |

## 2. 现状（代码事实）

- 分类页 `pages/product/list` 用原生导航栏（`list.json` 无 `navigationStyle`），页面内容从导航栏下方开始，**胶囊够不着内容区**——这是 N1 成立的前提。
- 门店头第一行 `.store-title-row`（`components/local-store-header/index.wxml`）现在是：`[图标 + 店名]` 与 `[营业状态胶囊]`，规格 §4.1 钉死「整行左对齐、店名可收缩可省略、状态胶囊不可收缩不换行」。
- 渠道切换的现成出口：`app.enterLocalChannel()`（同城，含位置许可）与 `setShoppingChannel('EXPRESS') + switchTab`（邮寄），`pages/user/index.js:150` 的 `goSwitchChannel` 就是这么写的，本批复用同一套，不新造。

## 3. 实测：这一行放得下

375px 宽、真实文案（店名「阿福凉菜」、状态「午间休息」、标识「同城配送 ▾」）下量过：店名块 12–103px，右侧组 209–363px，**中间余量 106px**，无溢出、无省略号。打烊时状态文案变长仍有余量。

若日后店名加长导致拥挤，备选是把状态胶囊移到第二行（配送规则行）左侧——本批不做。

## 4. 改动

| 文件 | 改动 |
|---|---|
| `components/local-store-header/index.wxml` / `.wxss` | 第一行右侧容器内增加渠道标识（新属性 `channel`，父页传入）；`.store-title-row` 改 `space-between`，右侧组内为「状态胶囊 + 渠道标识」 |
| `components/local-store-header/index.js` | 新增属性 `channel`；点击 `triggerEvent('switchchannel')`，组件自身不写全局状态 |
| `pages/product/list.wxml` / `.js` | 同城：门店头传 `channel`；邮寄：搜索框那一行右端渲染同款标识；两侧共用一个切换弹层；选中后走既有渠道出口 |
| `pages/index/index.wxss` | `.navbar-channel` 的 `right` 从 `24rpx` 改为胶囊左侧（约 `208rpx`，按胶囊 87px + 右边距 7px + 间距换算），修掉被遮挡 |

不动：底部标签栏、`app.json`、封面、服务端。

## 5. 验收

| 命令 | 期望 |
|---|---|

| `grep -n "right: 24rpx" apps/miniapp/pages/index/index.wxss` | 无结果（旧定位已改） |

### B. 真机
1. 同城分类页：门店头第一行右端见「同城配送 ▾」，不被胶囊遮挡；打烊时（状态文案变长）不换行、不挤压店名。
2. 点它 → 弹层两项、当前项打勾 → 选「全国邮寄」→ 页面变成邮寄分类页、标识变「全国邮寄 ▾」。
3. 邮寄分类页：搜索框那一行右端见标识，点它能切回同城（会先要位置许可）。
4. 主页（邮寄）：右上角「全国邮寄」标识完整可见、不再被胶囊压住。
5. 切换后购物车角标跟着变（两个渠道的车本来就是分开的）。

## 6. 风险

| 风险 | 预案 |
|---|---|
| 切到同城时位置许可被拒 | 复用 `enterLocalChannel` 既有处理（提示并留在原渠道），不新造分支 |
| 店名过长挤压标识 | 店名可收缩可省略（§4.1 既有规则），标识与状态胶囊不可收缩；超长时店名先省略 |
| 弹层与页面滚动打架 | 弹层加遮罩并 `catchtouchmove`，与项目现有弹层同一套写法 |

## 7. 上线

纯小程序改动，服务端零改动。合 main → 上传体验版 → 提审。可与已完成待提审的三批（分类页联动、完整门店头、自取时间必选）**合并成一次提审**。
