# 小程序双渠道导航与同城结算 —— 独立预览

对应 `docs/superpowers/plans/2026-09-07-miniapp-dual-channel-navigation-checkout.md` 的 **Task 1**。

**这是静态预览，不接任何接口、没有改一行业务代码。** 它的唯一用途是让店主在动手改代码之前
先确认版式、空间和文案。店主确认之前，Task 2 起的所有改动都不开始。

## 怎么看

```bash
node docs/design/miniapp-local-v2/serve.mjs
```

浏览器打开 <http://localhost:5195>。也可以直接把 `preview.single.html` 发出去——
那是内联了 CSS/JS/图标的单文件版，微信里点开、手机上看都行。

> ⚠️ 别直接双击 `preview.html`。`file://` 下相对路径的 CSS/JS 加载不出来，只会看到一堆无样式文字。
> 要么用上面的服务器，要么用 `preview.single.html`。

左边控制台四组开关：

| 组 | 作用 |
|---|---|
| 渠道 | 同城配送 / 全国邮寄。切换后四个主页面的内容全变，导航栏不变 |
| 四栏主页面 | 主页 / 分类 / 购物车 / 我的。**只有这四页有底部导航** |
| 流程页 | 同城结算 / 地址列表 / 地址编辑。按设计**不显示**底部导航 |
| 结算页状态 | 九种状态，只在结算页可点 |
| 叠加 | 优惠券弹层；「极限内容」= 超长店名 + 超长地址 + 超长券名 + 估算距离 |

右边两块画布是 iPhone 15（375×812）和 iPhone SE（320×568），同时渲染，改一处两边一起看。

「跑一次溢出自检」会量每个画布的横向滚动量、逐个元素测越界，命中的描红。
**本轮自检结果：7 个页面 × 2 个渠道 × 9 种结算状态 × 优惠券弹层 × 极限内容开关，
两种画布合计零溢出。**

## 这次预览要店主确认的几件事

1. **同城页头**：第一行只剩「🏪 阿福凉菜 [营业中]」，状态胶囊紧跟店名靠左，
   原来右上角那个「我的订单 ›」**删掉了**——订单统一从底部「我的」进。
   店名超长时省略号截断，胶囊永远完整不被挤扁（开「极限内容」看效果）。
2. **两个渠道长一个样**：同城也有主页/分类/购物车/我的四栏，和全国邮寄完全同一套导航。
   同城页不再是那个「进去就出不来」的孤岛。
3. **两个购物车是分开的**：件数不合并，角标只算当前渠道，结算路径也分开。
4. **结算页把该露的都露出来**：地址 → 配送 → 商品 → 优惠 → 餐具备注 → **金额明细** → 协议 → 提交栏。
   金额明细是新加的一张卡：商品金额 / 优惠券 / 配送费 / 积分赠品 / 应付金额，五行固定口径。
5. **不能提交的时候，绝不留一个能点的旧金额**：九种状态里只要有一种前置条件没满足，
   合计就显示「待计算」，按钮变灰，长原因写在按钮上方的提示条里，
   不塞进按钮（塞进去小屏必然溢出）。

## 一处想请店主拍板的

**「报价失败」这一状态，底部主按钮写着「重新获取运费」但是灰的、点不动**——
真正的重试按钮在上面「配送信息」卡里那个小圆角按钮。这是方案原文定下的口径
（Task 2 的测试字面量就是 `{ disabled: true, text: '重新获取运费' }`），预览照做了。

我的看法：灰着的按钮写着一个动词，顾客会去点、点了没反应。两个改法二选一：

- **A（推荐）** 主按钮改成灰色的「暂不可提交」，重试只留卡片里那一个，位置明确；
- **B** 主按钮变成可点的重试按钮，点了就重新报价。

店主选哪个都行，选完我改方案再动手。

## 两条实现约束，是这份预览顺手钉下来的

1. **`checkoutAction()` 是唯一的按钮状态判定**（`preview.js` 里那个纯函数）。
   优先级固定：地址 → 报价 → 业务阻塞 → 提交中；按钮文案只允许七种。
   Task 2 要用 `node:test` 锁的就是它，Task 7 接进 `pages/local/confirm.js` 的也是它——
   店主在这里看到的规则，就是将来真机上的规则。
2. **tabBar 页里的固定底栏用 `bottom: 0`，不要给 tabBar 留偏移。**
   微信的 tabBar 是画在 WebView 之外的原生组件，页面可视区本来就不含它；
   加偏移会在栏和 tabBar 之间留出一条空隙。仓库里 `pages/cart/index.wxss:133-143`
   已经是这个写法，跟着它走即可。（预览把 `.tabbar` 画成 `.screen` 的兄弟节点复刻这层关系；
   第一版把固定栏放在滚动层里，结果它跟着内容一起滚——真机上不会，但预览会骗人。）
